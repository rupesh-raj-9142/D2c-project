# LAXMI — Ghar Ka Swad, Har Bite Mein 🏺
> Modern, Premium Indian Pickle (Achar) Brand E-Commerce Platform

LAXMI is a high-conversion, responsive Direct-to-Consumer (D2C) e-commerce web platform for authentic, homemade Indian pickles. Built with an earthy, warm Indian culinary visual identity (deep red, mustard yellow, fresh green, warm heritage cream).

---

## 🌶️ Features

- **Dynamic Hero Section**: Highlighting sun-maturation, cold-pressed oils, and traditional heirloom recipes.
- **Trust & USP Badges**: 100% Authentic Taste, Premium Ingredients, Handcrafted with Care, Fresh Packaging.
- **Shop By Category**: Mango, Lemon, Green Chilli, Mixed (Pachranga), Garlic, and Regional specials.
- **Interactive Bestsellers**: Live weight variant selector (`250g` / `500g` / `1kg`) with instant dynamic price and savings recalculation.
- **Product Quick View Modal**: High-res image gallery, traditional ingredients breakdown, nutritional facts, and an **Indian 6-digit PIN code delivery estimator**.
- **Featured Combo Box**: 4-in-1 signature artisanal gift box with instant cart integration.
- **Slide-Over Cart Drawer**: Free delivery progress meter (orders above ₹499 unlock free shipping), coupon engine (`GHARKASWAD` for 10% off, `LAXMI50` for ₹50 off), and item management.
- **Full Checkout Flow**: Multi-step checkout with address validation and Indian payment method options (Instant UPI, Cards, Net Banking, COD).
- **Order Confirmation**: Animated celebration modal with generated order tracking ID (`LXMI-XXXXXX`).
- **User Authentication**: Sign In / Create Account modal with one-click Google mock auth and customer profile state.
- **Wishlist Management**: Save favourites and move items to cart with one click.
- **Persistent State**: Cart, wishlist, orders, and user profile persisted in browser `localStorage`.
- **Fully Responsive**: Optimized for desktop (4-column grid), tablet (2-column grid), and mobile (single-column cards, sticky drawers).

---

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+ Modules)
- **Styling**: Vanilla CSS3 (Custom Design System, CSS Variables, Flexbox/Grid, Responsive Media Queries)
- **Dev Tooling**: [Vite](https://vitejs.dev/)
- **Typography**: Google Fonts (*Playfair Display*, *Cinzel*, *Plus Jakarta Sans*)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/rupesh-raj-9142/D2c-project.git
cd D2c-project
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

### 4. Build for production
```bash
npm run build
```
